# 莱顿逻辑馆 · 建议章节构思

为保留谜题的逻辑严密性，每个章节的 intro 将背景限定在“寻找位置/安排”的逻辑场景中，ending 则是对该场景的回忆片段。

## 章节 1：赫尔曼的阶梯教室（困难/困难）
- **Intro**: 大学阶梯教室的桌椅重新排布了。赫尔曼为了争论算法性能，非要让五个同学代表五个核心，位置必须满足特定的指令限制。我们得在老教授走进教室前，把他们的实验台位排好。
- **Ending**: 我把最后一份草稿交给赫尔曼，他还在兴奋地挥舞着钢笔。窗外雨声阵阵，教授敲了敲黑板：“洛伦兹，你的算法结论很好，但座位可以先坐回去吗？”

## 章节 2：雨夜带你回家（普通/简单）
- **Intro**: 那年深秋的雨夜，五只等待领养的小猫（含你）躲在屋檐下。我手里只有五块不同口味的肉块和五种不同颜色的温暖坐垫，得按照收容所的编号，把你们一个个安顿进对应的暖窝里。
- **Ending**: 你终于停止了瑟瑟发抖，嗅了嗅碟子里的温牛奶。我把你裹进羊毛围巾，你轻轻蹭了蹭我的下巴。那天起，这里就是我们的家了。

## 章节 3：卢卡的休假午后（普通/困难）
- **Intro**: 卢卡休假回家，客厅乱得一塌糊涂。他的电竞设备、万用表、拆卸的机械零件、华夫饼模具和几本手写复盘手记散落一地。我得把它们各归其位，否则他拆完这个家，我今晚就没地方休息了。
- **Ending**: 卢卡把耳机摘下来，挠了挠头发，递给我一片刚烤好的华夫饼：“老爸，你还没发现吗？我把备用零件藏在模具盒里了，这叫‘分布式逻辑冗余’。”

## 章节 4：永动轮的断电之夜（困难/困难）
- **Intro**: 永动轮公司主控室突然断电，五个备份电源模块必须在系统崩坏前恢复供应。赫尔曼在黑暗中通过对讲机报出零星线索，我必须在控制台上把它们对应到正确的电压槽位里。
- **Ending**: 灯亮起的一瞬间，屏幕显示系统稳定。赫尔曼的声音从对讲机里传来，带着一丝劫后余生的笑意。这是我们最后一次并肩工作，那天后，我递交了辞呈，回到了莱顿。

---
建议顺序：Ch1 (高难度，赫尔曼线) -> Ch2 (舒缓，情感线) -> Ch3 (日常，卢卡线) -> Ch4 (高难度，伏笔/结局线)。
