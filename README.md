# 莱顿猫工坊 · 小游戏合集

小猫玩的小游戏都放这里，一个游戏一个单文件，打开就能玩。

| 游戏 | 文件 | 说明 |
| --- | --- | --- |
| 莱顿工坊 · 断电之夜 | `workshop_blackout.html` | 解谜小品，三个房间，线索凑齐两种结局 |
| 莱顿猫工坊 · 小鱼干放置 | `dried_fish_idle.html` | 放置增量，含离线收益与转生（鱼骨 / 九条命） |
| 莱顿逻辑馆 · 小猫斑马谜题 | `zebra_puzzle.html` | 斑马谜题合集，含自由题、19 个故事与每日挑战 |

## 设计原则

- 单文件、零依赖、离线可玩
- 先做最朴素的一层，好玩再加，不一口气堆系统
- 数字要诚实：显示多少，就是多少

## 莱顿逻辑馆 · 小猫斑马谜题

入口：[`zebra_puzzle.html`](zebra_puzzle.html)。模块源码、永久每日题档案、构建与自动运维说明见 [`zebra/README.md`](zebra/README.md)。前端发布仍为离线可玩的单文件；持续每日更新由服务器定时生成并提交留档。

故事模式现有 19 个独立事件，支持人物与本格推理标签筛选；事件内分阶段解谜、独立保存进度，可同步到其他设备。
